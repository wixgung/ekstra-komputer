Pertemuan 3: CIN dan Operator

Setelah belajar variabel dan tipe data, sekarang kita belajar cara membuat program yang bisa membaca input dari pengguna (pakai cin), lalu mengolahnya dengan operator. Materi ini dibagi jadi langkah-langkah kecil — setiap selesai satu langkah, ada uji paham singkat dulu sebelum bisa lanjut ke langkah berikutnya.

cin >> Operator Aritmatika Operator Perbandingan Operator Logika
01 · CIN Dasar

Membaca Satu Nilai dengan cin

cin dipakai untuk membaca nilai yang diketik pengguna lewat keyboard, lalu menyimpannya ke sebuah variabel — kebalikan dari cout yang menampilkan nilai ke layar.

📥 input

cin

Membaca nilai dari keyboard. Selalu dipasangkan dengan operator >> (arahnya ke variabel).

📤 output

cout

Menampilkan nilai ke layar. Dipasangkan dengan operator << (arahnya ke layar).

Cara gampang mengingat arah panahnya: cin >> variabel — nilai "masuk" ke variabel. cout << variabel — nilai "keluar" ke layar.

cin-satu-nilai.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int umur;
cout << "Masukkan umur kamu: ";
cin >> umur;
cout << "Umur kamu adalah " << umur << " tahun" << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Angka 17 di atas adalah yang diketik pengguna setelah program berhenti menunggu di baris cin >> umur;.

✏️ Ketik program ini sendiri di Dev-C++, jalankan dengan F11, lalu coba ketik angka umurmu sendiri.

02 · CIN Lanjutan

Membaca Banyak Nilai Sekaligus

Kalau butuh beberapa nilai sekaligus, kita bisa merangkai >> berkali-kali dalam satu baris — tidak perlu satu cin untuk tiap variabel.

cin-banyak-nilai.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int hari, bulan, tahun;
cout << "Masukkan tanggal (hari bulan tahun): ";
cin >> hari >> bulan >> tahun;
cout << "Tanggal: " << hari << "/" << bulan << "/" << tahun << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Ketiga angka dipisah dengan spasi saat diketik, lalu masuk berurutan: nilai pertama ke hari, kedua ke bulan, ketiga ke tahun.

!

Hati-hati: cin >> berhenti di spasi

Untuk tipe string, cin >> hanya membaca sampai spasi pertama. Kalau pengguna mengetik Made Wirawan, variabel string hanya akan berisi Made saja — kata "Wirawan" tidak ikut terbaca. (Untuk membaca kalimat penuh, dipakai perintah lain yang akan dibahas di pertemuan selanjutnya.)

✏️ Ketik program ini sendiri, coba jalankan dengan mengetik tiga angka dipisah spasi.

03 · Operator

Operator Aritmatika

Operator aritmatika dipakai untuk menghitung nilai dari dua angka atau lebih.

OperatorArtiContohHasil
+Penjumlahan5 + 27
-Pengurangan5 - 23
*Perkalian5 * 210
/Pembagian5 / 22 (kalau keduanya int)
%Sisa bagi (modulus)5 % 21

Perhatikan baris /: kalau kedua variabelnya bertipe int, hasil pembagian dibulatkan ke bawah (bagian desimal dibuang). Supaya hasilnya tetap punya desimal (misal 17/5 = 3.4), minimal salah satu variabelnya harus bertipe double atau float.

operator-aritmatika.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int a, b;
cout << "Masukkan dua bilangan bulat: ";
cin >> a >> b;
cout << "Jumlah: " << a + b << endl;
cout << "Selisih: " << a - b << endl;
cout << "Kali: " << a * b << endl;
cout << "Bagi: " << a / b << endl;
cout << "Sisa Bagi: " << a % b << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11
✏️ Ketik program ini sendiri, coba dengan angka yang berbeda dan tebak hasilnya sebelum menjalankan F11.

04 · Operator

Operator Perbandingan & Logika

Operator perbandingan dan logika menghasilkan nilai bool — true (ditampilkan sebagai 1) atau false (ditampilkan sebagai 0).

Operator Perbandingan

OperatorArtiContohHasil
==Sama dengan5 == 51 (true)
!=Tidak sama dengan5 != 31 (true)
>Lebih besar5 > 31 (true)
<Lebih kecil5 < 30 (false)
>=Lebih besar sama dengan5 >= 51 (true)
<=Lebih kecil sama dengan5 <= 30 (false)

Jangan tertukar: = (satu sama dengan) dipakai untuk mengisi nilai, sedangkan == (dua sama dengan) dipakai untuk membandingkan.

Operator Logika

OperatorArtiBernilai true jika...
&&ANDkedua kondisi bernilai true
||ORminimal salah satu kondisi bernilai true
!NOTmembalik nilai: true jadi false, false jadi true
operator-perbandingan.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int nilai;
cout << "Masukkan nilai ujian: ";
cin >> nilai;
cout << "Lulus (>=75): " << (nilai >= 75) << endl;
cout << "Nilai sempurna (==100): " << (nilai == 100) << endl;
cout << "Rentang aman (>=75 dan <=100): " << (nilai >= 75 && nilai <= 100) << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Perhatikan hasilnya ditampilkan sebagai angka 1 atau 0, bukan tulisan "true"/"false" — ini kebiasaan bawaan cout untuk nilai bool.

✏️ Ketik program ini sendiri, coba masukkan nilai yang berbeda-beda dan tebak hasilnya dulu sebelum menjalankan F11.

05 · Praktik Gabungan

Contoh Program Gabungan

Sekarang kita gabungkan cin dan operator dalam satu program sederhana: menghitung rata-rata nilai dan status lulus siswa.

gabungan.cpp🔒 ketik sendiri
#include <iostream>
#include <string>
using namespace std;
int main() {
string nama;
int nilaiUjian, nilaiTugas;
cout << "Nama: ";
cin >> nama;
cout << "Nilai Ujian: ";
cin >> nilaiUjian;
cout << "Nilai Tugas: ";
cin >> nilaiTugas;
int rataRata = (nilaiUjian + nilaiTugas) / 2;
bool lulus = rataRata >= 75;
cout << "Halo, " << nama << endl;
cout << "Rata-rata: " << rataRata << endl;
cout << "Status Lulus: " << lulus << endl;
return 0;
}
Simulasi jendela Console setelah ditekan F11

Penjelasan Bagian Penting

10
cin >> nama;

Karena nama bertipe string, ingat: sebaiknya diketik satu kata saja (tanpa spasi) supaya seluruhnya ikut terbaca — sesuai catatan di Langkah 02.

16
int rataRata = (nilaiUjian + nilaiTugas) / 2;

Tanda kurung dipakai supaya penjumlahan dihitung lebih dulu, baru hasilnya dibagi 2 — sama seperti aturan matematika biasa.

17
bool lulus = rataRata >= 75;

Hasil operator perbandingan (yang bertipe bool) bisa langsung disimpan ke sebuah variabel, tidak harus langsung dipakai di cout.

✏️ Ketik program ini sendiri, jangan copy-paste — supaya terbiasa dengan penulisannya.

06 · Praktik Mandiri

Latihan: Nilai Akhir dan Status Kelulusan

Latihan ini adalah variasi dari Contoh Program Gabungan di Langkah 05 — masih sama-sama memakai cin, operator aritmatika, dan operator perbandingan, hanya datanya sedikit berbeda. (Menghitung luas & keliling bangun datar akan kita bahas di pertemuan selanjutnya.)

Tugas

Lengkapi kerangka program di bawah supaya bisa membaca nama, nilai harian, dan nilai ujian dari pengguna lewat cin, lalu:

  • ▸Hitung rataRata dari nilai harian dan nilai ujian, memakai operator + dan /
  • ▸Buat variabel bool bernama lulus, isinya hasil rataRata >= 70
  • ▸Tampilkan nama, rata-rata, dan status lulus dengan cout

#include <iostream>

cout << "Nilai Harian: ";
cin >> ______;
cout << "Nilai Ujian: ";
