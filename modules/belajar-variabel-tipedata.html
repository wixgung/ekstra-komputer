Pertemuan 2: Variabel dan Tipe Data

Di pertemuan kedua ini kita belajar cara menyimpan data di dalam program — mulai dari apa itu variabel, tipe-tipe data dasar di C++, aturan memberi nama variabel, sampai deklarasi dan inisialisasi. Materi dibagi jadi langkah-langkah kecil — setiap selesai satu langkah, ada uji paham singkat dulu sebelum bisa lanjut ke langkah berikutnya.

Variabel Tipe Data Aturan Penamaan Deklarasi & Inisialisasi
01 · Pengenalan

Apa itu Variabel?

Variabel adalah nama yang kita berikan untuk sebuah tempat penyimpanan di memori komputer, supaya kita bisa menyimpan sebuah nilai dan memakainya lagi kapan saja selama program berjalan.

Bayangkan variabel seperti sebuah kotak berlabel. Kita bisa menaruh sesuatu di dalamnya, membaca isinya, atau mengganti isinya dengan nilai baru — dan label di kotak itu (nama variabel) tidak berubah meskipun isinya berganti.

01

Nama Variabel

Sebutan unik yang kita pakai untuk memanggil variabel, misalnya umur atau nama.

02

Tipe Data

Menentukan jenis nilai apa yang boleh disimpan, misalnya angka bulat, angka desimal, atau teks.

03

Nilai / Isi Data

Isi yang sedang disimpan di dalam variabel itu saat ini — ini "barang" yang ada di dalam kotaknya, dan bisa berubah selama program berjalan.

Tiga hal ini — nama variabel, tipe data, dan nilai/isi data — selalu melekat pada setiap variabel di C++.

Tipe Data Dasar di C++

Setiap variabel di C++ wajib punya tipe data. Tipe data inilah yang memberi tahu komputer jenis nilai apa yang boleh disimpan, dan berapa banyak memori yang perlu disiapkan untuknya.

TipeUntuk MenyimpanContoh DeklarasiContoh Nilai
shortBilangan bulat, rentang lebih kecil dari intshort jumlahKursi = 32;32, -100
intBilangan bulat (tanpa koma), paling umum dipakaiint umur = 17;17, -5, 0
longBilangan bulat, rentang lebih besar dari intlong jumlahPenduduk = 5000000;5000000
floatBilangan desimal (presisi tunggal)float tinggi = 165.5;165.5
doubleBilangan desimal (presisi lebih tinggi)double luas = 12.75;12.75

Perhatikan tanda kutipnya: char selalu pakai kutip satu ('A') dan isinya cuma satu karakter, sedangkan string pakai kutip dua ("Wayan") dan boleh berisi banyak karakter.

Bilangan Bulat: short vs int vs long

Ketiganya sama-sama untuk bilangan bulat. Bedanya ada di seberapa besar jatah memori yang disediakan — semakin besar jatahnya, semakin besar juga angka yang bisa ditampung.

jatah paling kecil

short

Biasanya diberi jatah memori 2 byte — paling hemat, tapi angka yang bisa ditampung juga paling terbatas.

jatah standar

int

Biasanya diberi jatah memori 4 byte. Ini pilihan "standar" untuk hampir semua kebutuhan sehari-hari.

jatah paling besar

long

Jatah memorinya paling besar. Dipakai kalau angkanya diperkirakan terlalu besar untuk ditampung int.

Bilangan Desimal: float vs double

Keduanya untuk bilangan berkoma. Bedanya soal ketelitian — double lebih teliti daripada float. Kalau ragu mau pakai yang mana, pakai double saja sebagai default.

Khusus string, kebiasaan yang baik adalah menambahkan baris #include <string> di awal program setiap kali memakai tipe data ini, supaya program dijamin bisa dikompilasi di compiler manapun.

02 · Aturan Penulisan

Aturan Penamaan Variabel

Nama variabel tidak boleh sembarangan — ada aturan yang wajib diikuti supaya kode bisa dijalankan (dikompilasi) dengan benar.

1

Diawali huruf atau garis bawah

Nama variabel harus dimulai dengan huruf (a-z, A-Z) atau garis bawah _ — tidak boleh dimulai dengan angka.

2

Hanya huruf, angka, garis bawah

Tidak boleh ada spasi atau simbol lain seperti -, #, atau @ di dalam nama variabel.

3

Case-sensitive

Huruf besar dan kecil dianggap berbeda. Variabel nilai, Nilai, dan NILAI adalah tiga variabel yang berbeda.

4

Tidak boleh memakai kata kunci C++

Kata seperti int, if, class, atau return sudah punya arti khusus di C++, jadi tidak bisa dipakai sebagai nama variabel.

5

Sebaiknya deskriptif

Ini bukan aturan wajib, tapi kebiasaan yang baik: nama seperti nilaiUjian jauh lebih mudah dipahami daripada sekadar x.

03 · Praktik

Deklarasi dan Inisialisasi

Ada dua istilah yang sering dipakai bergantian, padahal artinya berbeda:

langkah 1

Deklarasi

Proses "membuat" variabel — memberi tahu compiler bahwa akan ada sebuah kotak bernama tertentu dengan tipe data tertentu. Contoh: int umur;

langkah 2

Inisialisasi

Proses mengisi variabel dengan nilai pertama kalinya. Contoh: umur = 17;

Keduanya bisa dilakukan sekaligus dalam satu baris — cara ini yang paling sering dipakai:

deklarasi.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int umur; // deklarasi: kotak "umur" dibuat, isinya belum ditentukan
umur = 17; // inisialisasi: kotak "umur" diisi belakangan
int nilai = 90; // deklarasi + inisialisasi sekaligus (paling umum dipakai)
cout << "Saya Umur " << umur << endl;
cout << "Nilai ekstra saya " << nilai << endl;
return 0;
}
Simulasi tampilan Console setelah ditekan F11

Kalau ada beberapa variabel dengan tipe data yang sama, kita juga bisa mendeklarasikannya sekaligus dalam satu baris, dipisah dengan koma:

deklarasi-ganda.cpp🔒 ketik sendiri
#include <iostream>
using namespace std;
int main() {
int hari, bulan, tahun;
hari = 17; bulan = 8; tahun = 1945;
cout << hari << "/" << bulan << "/" << tahun << endl;
return 0;
}
Simulasi tampilan Console setelah ditekan F11
✏️ Ketik kedua program ini sendiri di Dev-C++, jangan copy-paste — supaya terbiasa dengan penulisannya.

04 · Bekal Tambahan

Hal Penting Lainnya

Beberapa kesalahan kecil yang paling sering terjadi saat baru belajar variabel dan tipe data.

⚠️ kutip keliru

char vs string

char selalu pakai kutip satu dan cuma satu karakter, misalnya char g = 'A';. Kalau isinya lebih dari satu karakter atau pakai kutip dua, itu tandanya seharusnya memakai string.

⚠️ tipe tidak cocok

Nilai harus sesuai tipe

Jangan mengisi bool dengan angka selain konteks true/false, atau mengisi int dengan teks — kode bisa gagal dikompilasi atau hasilnya tidak sesuai harapan.

Beberapa contoh kata kunci C++ yang tidak boleh dipakai sebagai nama variabel: int, short, long, float, double, char, bool, if, else, for, while, return, class. Kalau nama variabel ditolak compiler padahal terlihat wajar, coba periksa apakah nama itu kebetulan sama dengan salah satu kata kunci ini.

05 · Praktik Gabungan

Contoh Program Lengkap

Sekarang mari gabungkan beberapa tipe data sekaligus dalam satu program sederhana yang menampilkan data seorang siswa.

datasiswa.cpp🔒 ketik sendiri
#include <iostream>
#include <string>
using namespace std;
int main() {
string nama = "Kadek";
int umur = 16;
double tinggi = 165.5;
char kelas = 'B';
bool aktifEkskul = true;
cout << "Nama: " << nama << endl;
cout << "Umur: " << umur << endl;
cout << "Tinggi: " << tinggi << endl;
cout << "Kelas: " << kelas << endl;
cout << "Aktif Ekskul: " << aktifEkskul << endl;
return 0;
}
Simulasi tampilan Console setelah ditekan F11
✏️ Ketik program ini sendiri, ganti isinya dengan data dirimu, lalu jalankan dengan F11.

Penjelasan Bagian Penting

2
#include <string>

Pustaka tambahan yang direkomendasikan untuk selalu disertakan setiap kali memakai tipe data string, supaya program dijamin bisa dikompilasi di compiler manapun.

7-11
string nama = "Kadek"; ...

Lima variabel dideklarasikan sekaligus diisi (deklarasi + inisialisasi), masing-masing dengan tipe data yang sesuai jenis datanya.

17
cout << aktifEkskul;

Perhatikan hasilnya di Console: nilai bool true ditampilkan sebagai angka 1 (dan false sebagai 0), bukan sebagai tulisan "true"/"false". Ini kebiasaan bawaan cout di C++.
